3. Adjust the repayment logic (core maths)
Find where the calculator currently computes the monthly repayment in arrears.

It will look roughly like:

ts
Copy code
const rMonthly = annualRate / 100 / 12;
const n = termMonths;

let monthlyPrincipalInterest: number;

if (rMonthly > 0) {
  // Balloon-aware annuity in arrears:
  const effectivePrincipal =
    amountFinanced - balloonAmount / Math.pow(1 + rMonthly, n);
  monthlyPrincipalInterest =
    effectivePrincipal * (rMonthly / (1 - Math.pow(1 + rMonthly, -n)));
} else {
  // Zero-rate case:
  const principalMinusBalloon = amountFinanced - balloonAmount;
  monthlyPrincipalInterest = principalMinusBalloon / n;
}

// Then:

3.1 Add the advance conversion
Immediately after monthlyRepayment (the arrears figure) is computed, add:

ts
Copy code
let adjustedMonthlyRepayment = monthlyRepayment;

if (form.paymentInAdvance) {
  if (rMonthly > 0) {
    adjustedMonthlyRepayment = monthlyRepayment / (1 + rMonthly);
  } else {
    // rMonthly === 0 → arrears and advance are the same in amount,
    // only timing differs, so we keep the same repayment.
    adjustedMonthlyRepayment = monthlyRepayment;
  }
}
