4. Repayment calculation logic
All calculations should update live as inputs change, after basic validation.

Definitions:

Principal P = amount financed = vehiclePrice - deposit - tradeIn + payout.

Term in months n = termMonths.

Annual interest rate annualRate in percent.

Monthly rate r:

ts
Copy code
const r = annualRate / 100 / 12;
Balloon amount R = balloonAmount.

4.1 Normal case – r > 0
Use standard annuity with residual:

Formula for the principal and interest component of the monthly repayment:

text
Copy code
effectivePrincipal = P - R / (1 + r)^n

monthlyPrincipalInterest =
  effectivePrincipal * [ r / (1 - (1 + r)^(-n)) ]
If n <= 0 or P <= 0:

Treat repayment as 0 and do not attempt calculation.

4.2 Zero interest case – r == 0
If annualRate is 0 or extremely close to 0 (for example absolute value < 1e-8):

Then the principal over term is:

ts
Copy code
monthlyPrincipalInterest = (P - R) / n;
If (P - R) <= 0 or n <= 0, repayment is 0.

4.3 Monthly fee and derived repayments
Monthly repayment:

ts
Copy code
monthlyRepayment = monthlyPrincipalInterest + monthlyFee;
Fortnightly repayment:

ts
Copy code
fortnightlyRepayment = monthlyRepayment * 12 / 26;
Weekly repayment:

ts
Copy code
weeklyRepayment = monthlyRepayment * 12 / 52;
Round each displayed repayment to two decimal places with an existing round2 helper:

ts
Copy code
function round2(n: number) {
  return Math.round(n * 100) / 100;
}
Do not show negatives. If the computed repayment is negative or NaN due to bizarre inputs, clamp to 0.

6.1 File naming logic
Two cases:

Client name / reference is empty (or whitespace only)

Filename pattern:
Quote - <YYYY-MM-DD> - <index>.pdf

<YYYY-MM-DD> is today’s date in ISO format.

<index> is a three digit counter for that day (001, 002, 003, ...).

Client name / reference is provided

Clean the input (trim and replace invalid filename characters /\:*?"<>| with space or dash).

Filename pattern:
<ClientOrRef> - Quote - <YYYY-MM-DD> - <index>.pdf

Same date and index rules as above.

Index behaviour:

Use localStorage with key like:
"loan_calc_quote_counter_<YYYY-MM-DD>".

Read it on export:

If missing: start at 1.

If present: parse and increment.

Use that number for <index>, padded with padStart(3, "0").

Update localStorage after each export.

Examples:

No name, first export 2025-12-09:
Quote - 2025-12-09 - 001.pdf

Name “Fadia Hassan”, second export that day:
Fadia Hassan - Quote - 2025-12-09 - 002.pdf
