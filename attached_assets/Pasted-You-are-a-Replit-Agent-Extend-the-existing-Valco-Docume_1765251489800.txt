3. Traffic light field status system
Every important text input in the Private Sale form must have a status:

"missing" → red (required, currently blank)

"autoFilled" → yellow (auto-filled by parser, user hasn’t confirmed)

"confirmed" → green (user has interacted and the field has content)

Also track initialSource:

"empty" – started empty

"manual" – first filled by user

"parser" – first filled by the DoxAI parser

3.1 Fields that must use traffic lights
At minimum, the following required fields use the status system:

vendorName

vendorAddress

buyerName

buyerAddress

vehicleMake

vehicleModel

vehicleVin

vehicleRegistration

vehicleOdometer

invoiceAmount

Other fields (description, engine number, build/compliance) can also use it but may be optional.

3.2 Initialisation
When the tab loads:

For each required field:

value = ""

initialSource = "empty"

status = "missing" (red)

3.3 Manual entry before parsing
If user types into a blank field:

On first change:

initialSource = "manual"

status = "confirmed" (green)

Subsequent changes keep "confirmed" unless user deletes everything.

If a previously confirmed field is cleared and blurred:

If required: set status = "missing".

3.4 After DoxAI parsing
When a DoxAI report is parsed and yields values:

For each field:

If field.value is empty:

Set value = parsedValue.

Set initialSource = "parser".

Set status = "autoFilled" (yellow).

If field.value is non-empty and status === "confirmed":

Do not overwrite.

If parser cannot find a value and the field is empty:

Keep status = "missing".

3.5 User confirmation after parsing
For a field with status === "autoFilled":

On focus: do nothing.

On blur:

If value is still non-empty:

Set status = "confirmed" (green).

If value was cleared:

Set status = "missing" (red if required).

For status === "missing":

When user types a non-empty value, immediately set status = "confirmed".
