3.2 Invoice number tracking - lib/storage/invoiceNumber.ts
LocalStorage key: "valco_invoice_last_number"

Number format is 2025-xxxxx where the numeric portion increments by one.

Seed starting point: 2025-04564.

Provide:

ts
Copy code
export function getNextInvoiceNumber(): string;
export function commitInvoiceNumber(invoiceNumber: string): void;
Logic for getNextInvoiceNumber:

Read localStorage.

If no last number is stored:

Return "2025-04564" but do not write yet.

If a string exists:

Parse with regex /^(\d{4})-(\d+)$/.

Keep the first group (year) unchanged.

Increment the numeric part by one.

Format back as year-newNumber (preserve zero padding of the original numeric segment).

Return that as the suggestion.

commitInvoiceNumber updates localStorage with the final invoice number after a PDF has been generated successfully.

4. Money and date helpers
Create lib/money.ts:

ts
Copy code
export function round2(n: number): number {
  return Math.round(n * 100) / 100;
}

export function calculateTotals(
  items: InvoiceLineItem[],
  mode: TaxInvoiceMode
): { subtotalExGst: number; gstTotal: number; totalIncGst: number } {
  let subtotalEx = 0;
  let gst = 0;
  let totalInc = 0;

  for (const item of items) {
    const inc = Number.isFinite(item.amountIncGst) ? item.amountIncGst : 0;
    if (mode === "GST_INC") {
      const ex = inc / 1.1;
      const lineGst = inc - ex;
      subtotalEx += ex;
      gst += lineGst;
      totalInc += inc;
    } else {
      // NO_GST mode
      subtotalEx += inc;
      totalInc += inc;
    }
  }

  subtotalEx = round2(subtotalEx);
  gst = round2(gst);
  totalInc = round2(totalInc);

  return { subtotalExGst: subtotalEx, gstTotal: gst, totalIncGst: totalInc };
}
Create lib/dates.ts:

todayIso(): string - returns current date in YYYY-MM-DD based on local time.

addDays(dateIso: string, days: number): string - adds days, returns ISO.

formatDisplay(dateIso: string): string - returns DD/MM/YYYY.
