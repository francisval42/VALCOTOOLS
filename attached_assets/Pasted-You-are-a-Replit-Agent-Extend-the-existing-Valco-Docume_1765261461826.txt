```ts

export type BudgetFrequency = "weekly" | "fortnightly" | "monthly";

export type RateType = "fixed" | "variable" | "";

export interface OtherLender {

  exclusionReason: string;

export interface FormData {
  // Loan type
  loanType: LoanType;

  // Client details
  firstName: string;
  lastName: string;

  // Loan details
  purpose: string;            // required
  isSecured: boolean;         // auto true for consumer_car

  lender: string;             // required

1.4 Validation rules
Implement validation:

Loan amount: required, numeric 2,000–250,000.

Budget amount: required, numeric min 50.

Term: required, one of [12, 24, 36, 48, 60, 72, 84].

Rate type: required.

rateTypeReasons: at least 1.

Lender: required (non-empty).

LenderReasons: at least 1.

IncomeVerification: at least 1.

ExpenseVerification: at least 1.

SecurityDescription: required if isSecured === true and loanType !== "consumer_car" (for consumer_car, auto text is fine).

ChangeDescription + ChangeMitigation: required when changeInCircumstances === "yes".

MonthlyBudget:

Convert budgetAmount according to budgetFrequency:

weekly → amount * 52 / 12

fortnightly → amount * 26 / 12

monthly → amount

AffordabilityFlag rule:

Compute:

ts
Copy code
const loanAmt = parseFloat(loanAmount);
const monthlyBudget = computed;
const minimumRequired = Math.max(loanAmt * 0.005, 100);
const isAffordabilityFlagged = monthlyBudget < minimumRequired;
If isAffordabilityFlagged === true, then affordabilityJustification is required and the note must use the “flagged” variant text.

Show error messages under offending fields and block “Generate note” until valid.
